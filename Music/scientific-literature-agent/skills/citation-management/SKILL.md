# Citation Management

## Purpose
Format citations from explicitly supplied bibliographic metadata.

## Inputs
Authors, year, title, venue, and optional DOI.

## Processing
Validate fields and format a deterministic APA-like citation.

## Outputs
Style label and formatted citation.

## Limitations
Formatting does not verify metadata or DOI resolution.

## Expected behavior
Reject malformed inputs and never invent missing evidence.
